# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** โหมดมืดทั้งระบบพร้อมสวิตช์ โหมดสว่างเหมือนเดิมเป๊ะ

**Architecture:** `@custom-variant dark` + CSS variables สำหรับ shell/utilities, ไล่เติม `dark:` ให้คลาส inline ทุกไฟล์, toggle จำค่าใน localStorage

**Tech Stack:** Next.js App Router, Tailwind CSS v4, Vitest, Playwright

**Spec:** `docs/superpowers/specs/2026-10-06-dark-mode-design.md`

## Global Constraints

- เปลี่ยนแค่ classes — ห้ามแตะ logic/API/DB/scan-service/auth
- variant: `@custom-variant dark (&:where(.dark, .dark *));`
- variables: `--bg, --surface, --border, --text, --muted` (สว่าง = ค่า slate เดิม)
- storage key: `stock-theme` ค่า `light|dark|system` (default `system`)
- toggle: `data-testid="theme-toggle"`, ไอคอน ☀/🌙, อยู่ใน NavBar
- โหมดสว่างต้องเหมือนเดิมทุกพิกเซล (ห้ามเปลี่ยนคลาส light)

## Review Focus

- หน้า login (นอก `(app)`) มืดด้วย — คาดว่า layout root ครอบถึง
- dropdown ปฏิทิน/select ในโหมดมืด — คาดว่า `color-scheme: dark` เอาอยู่
- ตารางรายงานตัวหนังสือจาง — คาดว่าไล่ text-slate-400→300 ครบ
- กด toggle แล้วรีเฟรช — คาดว่า inline script + localStorage จำค่า
- หน้าสแกน pastel ในโหมดมืด — คาดว่ามีรุ่น .dark ของมันเอง ไม่ใช่แค่ invert
